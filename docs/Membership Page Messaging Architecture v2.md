# **FIRST NATIONS ACTION NETWORK**

# **Membership Page Messaging Architecture v2**

## **Purpose**

The Membership Page exists to answer one question:

### **Why should our organisation join the First Nations Action Network?**

The page should not focus primarily on software, features or technology.

The page should focus on connection, participation, capacity building and community impact.

The goal is to help organisations see themselves as part of a larger network working towards positive change.

# **The Core Promise**

## **You Don't Have To Do This Work Alone**

Many organisations are working hard to strengthen communities, build relationships and create positive change.

The First Nations Action Network exists to help organisations connect, collaborate and grow their impact together.

Membership provides access to a growing national network, shared resources, learning opportunities and community organising infrastructure designed to strengthen local action.

# **The Membership Transformation**

## **Before Joining**

Organisations often experience:

-   Limited capacity
-   Volunteer burnout
-   Isolation from similar organisations
-   Difficulty sustaining momentum
-   Limited access to resources
-   Challenges engaging supporters and communities

## **After Joining**

Organisations become part of a growing national network with access to:

-   Shared learning
-   Collaboration opportunities
-   Community organising infrastructure
-   Leadership development
-   Community visibility
-   Ongoing support

Membership helps organisations strengthen their ability to engage communities and create lasting impact.
