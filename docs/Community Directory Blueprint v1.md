# **FIRST NATIONS ACTION NETWORK**

# **Community Directory Blueprint v1**

## **Purpose**

The Community Directory serves as a national directory of organisations, groups, networks and initiatives working to strengthen communities and create positive change across Australia.

The directory exists to:

-   Increase visibility
-   Strengthen collaboration
-   Improve discoverability
-   Support relationship building
-   Showcase community activity
-   Establish the First Nations Action Network as a central hub for community information

The directory is a public-facing resource and one of the primary trust-building assets of the First Nations Action Network.

# **Vision**

## **Australia's Most Comprehensive Directory Of First Nations And Community Organisations**

The directory aims to become the most comprehensive and discoverable collection of:

-   First Nations organisations
-   Native Title groups
-   Ally organisations
-   Reconciliation groups
-   Community groups
-   Cultural organisations
-   Advocacy organisations
-   Workplace networks
-   Social enterprises

The directory should help people discover organisations, connect with communities and identify opportunities for collaboration.

# **Strategic Objectives**

## **Objective 1**

# **Strategic Value**

The Community Directory is more than a directory.

It is a national map of community activity.

It helps people discover organisations, strengthen relationships and understand the breadth of work being undertaken across Australia.

As the directory grows, it becomes one of the strongest assets in the First Nations Action Network ecosystem.

# **Vision Statement**

The Community Directory exists to connect people, organisations and communities by making community leadership, community action and community impact more visible across Australia.
